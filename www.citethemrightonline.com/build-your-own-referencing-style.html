      Build Your Institution’s Referencing Style

      This CTR feature lets your institution create a customised referencing style by adapting one of our core styles. Configure in-text citations and reference-list patterns, preview how checking works on sample text, and export a reusable JSON profile to share across modules and cohorts.

      Style Builder In-Text Rules Reference Patterns Live Tester Export / Import How It Works

      Style Builder

      Choosing a base style loads sensible defaults. You can further tweak rules below.

      In-Text Citation Rules

      Note: These rules affect how the checker detects in-text citations; they do not format citations for display.

      Reference Detection Patterns

      Use simple tokens to describe how references appear in your list:

      Source typePattern
      Book
      Journal article
      Chapter
      Website
      Generic (fallback)

      The checker converts these templates into flexible detectors (e.g., accepting “(YYYY)” or “, YYYY.” depending on your settings).

      Live Tester

      Paste sample text. Ensure the heading References appears before your list.

      Export / Import Style

      JSON contains only your detection rules (no essay data). You can share it with colleagues to standardise checking across modules.

      
    
      

    
    
      
        
      How This Feature Works
      
        
      Detection, not formatting. The builder configures how the checker detects in-text citations and reference entries. It does not render formatted outputs.
      
        
      Two-stage parsing. Your pasted text is split at the heading “References”. The first part is scanned for in-text citations; the second part is scanned line-by-line for references using your patterns.
      
        
      Author–date vs numeric. Author–date modes look for patterns such as (Smith, 2022) and Smith (2022), with optional et al. and corporate authors. Numeric modes look for [1], (1), and ranges if enabled.
      
        
      Matching logic. Each in-text citation is matched to a reference containing the same year or number. For et al., only the first surname needs to appear in the reference line.
      
        
      Output: Matched, Missing reference, Uncited reference.
      
        
      Limitations: This is a structural checker. It won’t validate italics, punctuation, order, or metadata completeness. Complex surnames, legal citations (OSCOLA), or unusual media may require tuning.
